# snap-ocr v1.1

macOS 截图取字托盘工具（Apple Silicon）。

## 下载

`snap-ocr-v1.1.dmg` —— 打开后把 snap-ocr.app 拖入 Applications

## v1.1 新增

- **设置面板**（托盘 → 设置…）：快捷键自定义、OCR 服务地址可指向远程、大模型配置预留（下版本截图翻译）
- **授权自动弹窗**：输入监控/屏幕录制各弹一次，点允许即可，不再手动去设置里添加
- 默认热键：`⌥⇧O` 截图 ｜ `⌥⇧I` 截图并识别
- 大量稳定性修复（热键换绑、权限判定、截取偏移）

## 首次使用

1. **过 Gatekeeper（仅一次）**：右键 snap-ocr.app → 「打开」→ 再点「打开」
2. 允许弹出的「键盘/输入监控」「屏幕录制」授权，各重启一次应用
3. 启动后只有菜单栏「s」托盘图标，无 Dock 图标

## 用法

`⌥⇧O` 或点托盘 → 拖框 → 工具栏标注（矩形/椭圆/直线/箭头/马赛克/文字/撤销）→
回车/双击 = 复制到剪贴板；`📋 OCR` = 识别取字；`💾 保存` = 另存 PNG。

OCR 需要服务端：设置 → 通用 → OCR 服务地址填局域网地址（如
`http://192.168.1.10:8000`）→ 点「测试」→ 保存。
