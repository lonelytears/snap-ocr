# snap-ocr v1.0

macOS 截图取字托盘工具（Apple Silicon）。

## 下载

`snap-ocr-v1.0.dmg` —— 打开后把 snap-ocr.app 拖入 Applications

## 首次使用

1. **过 Gatekeeper（仅一次）**：应用未签名公证，右键 snap-ocr.app → 「打开」→ 再点「打开」
2. **授权（各一次）**：
   - 屏幕录制 —— 截图与标注必需
   - 辅助功能 —— 全局热键 ⌥⇧O（不授可用托盘菜单触发）
3. 启动后只有菜单栏「s」托盘图标，无 Dock 图标

## 用法

托盘「s」或 `⌥⇧O` → 拖框 → 工具栏标注（矩形/椭圆/直线/箭头/马赛克/文字/撤销）→
回车或双击 = 复制到剪贴板；`📋 OCR` = 识别取字；`💾 保存` = 另存 PNG。

## 已知限制

- OCR 依赖本机 `127.0.0.1:8000` 识别服务，本包未随附（点 OCR 会提示服务不可达，其余功能不受影响）
- 仅 Apple Silicon（M 系列）
- 未签名公证，企业管控环境可能拦截
