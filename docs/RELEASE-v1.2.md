# snap-ocr v1.2

macOS 截图取字托盘工具（Apple Silicon）。

## v1.2 新增

- **自动检查更新**：每天自动检查新版本（GitHub Releases），发现新版弹窗一键更新——自动下载、校验、安装并重启，无需重新下载 DMG
- **强制更新保障**：重要版本可强制升级（旧版弹窗不可跳过），始终用上最新修复
- 设置面板新增「关于」页：版本号、自动更新开关、手动「立即检查」
- 版本号单一来源管理，打包/发布/客户端一致
- 修复：重打包后系统授权（输入监控/屏幕录制）失效的问题（v1.1 用户升级后自动受益，不再需要反复授权）

## 从 v1.1 升级

- 已装 v1.1 的用户：下载本页 DMG 覆盖安装一次（v1.2 起之后的更新全部自动完成）
- 授权不再丢失：本版起同一签名身份 + 固定安装路径，每次更新后「辅助功能/屏幕录制」授权保持有效

## 首次使用

1. **过 Gatekeeper（仅一次）**：右键 snap-ocr.app → 「打开」→ 再点「打开」
2. 允许弹出的「键盘/输入监控」「屏幕录制」授权，各重启一次应用
3. 启动后只有菜单栏「s」托盘图标，无 Dock 图标
4. 默认热键：`⌥⇧O` 截图 ｜ `⌥⇧I` 截图并识别
